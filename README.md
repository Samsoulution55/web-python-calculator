# 🧮 Python Web Calculator

A clean, responsive full-stack web application built using **Python** and the **Flask** micro-framework. This project demonstrates clean folder structuring, dynamic routing, and separation of backend logic from front-end styling.

## 🚀 Features
* **Full-Stack Architecture:** Back-end mathematics processed entirely through Python.
* **Separation of Concerns:** Clean division between python controller (`app.py`), structural templates (`templates/index.html`), and presentation layers (`static/style.css`).
* **Responsive Card UI:** Clean design featuring placeholder input states and conditional result panels.

## 🛠️ Tech Stack
* **Backend:** Python 3, Flask
* **Frontend:** HTML5, CSS3

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://127.0.0.1:5000`
